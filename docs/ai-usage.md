# AI Usage

AI tools were used as an aid during development. Architectural and implementation decisions were done and accepted by the author.

## Usage Log

### OpenAI GPT model / ChatGPT:

1. **iCalendar investigation**
   - Used an OpenAI GPT model to understand the relevant RFC 5545 `VFREEBUSY` structure and free/busy semantics.

### OpenAI Codex

1. **Architecture review and diagrams**
   - Used OpenAI Codex to generate Mermaid diagram syntax from the given architectural concepts and to pinpoint plausible weaknesses and unaddressed cases within the architectural decisions.

2. **Project foundation**
   - Used OpenAI Codex to create and validate the configuration for: npm, TypeScript, and test-runner.

3. **Canonical scheduling model**
   - Used OpenAI Codex to implement and validate the canonical scheduling model, meeting-rule configuration, and focused model tests.

4. **Reference data loading**
   - Used OpenAI Codex to implement and validate the people-directory parser, limited free/busy calendar parser, startup reference-data loader, and focused integration tests.
